# Remove Desktop/Electron Build Tooling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Claudable web-only by removing the Electron desktop build/package tooling entirely — the app already runs standalone via `npm run dev`/Docker, and nothing in application code depends on Electron.

**Architecture:** Pure removal, no new subsystem. Two tasks: (1) delete the Electron runtime/build surface and verify the app still builds/tests/lints clean without it, (2) bring README.md's documentation in line with the new reality.

**Tech Stack:** Next.js App Router, TypeScript, npm.

**Spec:** project has no living `spec.md` — no spec-sync task.

**Design record:** `.flow/specs/2026-08-27-remove-desktop-electron-design.md`

## Global Constraints

- Full verification gate: `npm run type-check && npm test && npm run lint && npm run build`.
- Commit messages: English, imperative mood, matching this repo's existing convention (see `git log`).
- This is a pure removal with a pre-verified scope (see design record) — no application code in `app/`, `lib/services/`, or any API route branches on desktop-vs-web. Do not go looking for "just in case" desktop-awareness to preserve; there isn't any.
- `engines.node`'s `>=22.12.0` value in `package.json` stays unchanged — only fix the documentation that (incorrectly, after this change) attributes it to Electron. Lowering the Node floor is a separate decision this plan does not make.

### Task 1: Remove the Electron runtime, build config, and dependencies

**Files:**
- Delete: `electron/main.js`, `electron/preload.js`, `electron/wait-for-url.js` (whole `electron/` directory)
- Delete: `index.js`
- Delete: `scripts/run-desktop.js`
- Modify: `package.json`
- Modify: `package-lock.json` (regenerated by `npm install`, not hand-edited)
- Modify: `.gitignore`

**Interfaces:** None — nothing else in the codebase imports from `electron/`, `index.js`, or `scripts/run-desktop.js`. Confirmed by grep during design: `scripts/run-web.js`'s `startWebDevServer`/`parseCliArgs` (which `run-desktop.js` imports) has no reverse dependency — deleting `run-desktop.js` does not touch `run-web.js`.

- [ ] **Step 1: Delete the Electron source files**

```bash
git rm -r electron/
git rm index.js
git rm scripts/run-desktop.js
```

- [ ] **Step 2: Remove Electron from `package.json`**

Remove the `"main": "index.js"` field entirely (this project isn't `require()`d by anything — it was Electron's entry point and nothing else uses it).

Remove these four scripts:
```json
    "dev:desktop": "node scripts/run-desktop.js",
    "dev:electron": "npm run dev:desktop",
```
```json
    "build:desktop": "npm run build && electron-builder",
    "package:mac": "npm run build && electron-builder --mac",
    "package:win": "npm run build && electron-builder --win",
    "package:linux": "npm run build && electron-builder --linux",
```
Keep `"build": "next build --webpack"` and `"dev"`/`"dev:web"` — those aren't Electron-specific.

Remove these two devDependencies:
```json
    "electron": "^44.0.0",
    "electron-builder": "^26.15.3",
```

Remove the entire top-level `"build"` object (electron-builder's config block — `appId`, `productName`, `files`, `extraResources`, `asar`, `asarUnpack`, `directories`, `mac`, `win`, `linux`). It has no purpose once `electron-builder` is gone.

Leave `"engines": { "node": ">=22.12.0", "npm": ">=10.0.0" }` exactly as-is — see Task 2 for why the *documentation* around this number changes but not the number itself.

- [ ] **Step 3: Remove the now-dead electron-builder output directories from `.gitignore`**

Remove:
```
dist/
release/
```
(These were `electron-builder`'s build output directories — `npm run build` outputs to `.next/`, already covered by the `/.next/` rule above it in the file. Nothing will ever write to `dist/`/`release/` again after this task.)

- [ ] **Step 4: Regenerate `package-lock.json` and verify**

```bash
npm install
npm run type-check && npm test && npm run lint && npm run build
```
Expected: `npm install` completes and updates `package-lock.json` to drop `electron`/`electron-builder` and their transitive dependencies; all four gate commands PASS. Confirm `package-lock.json`'s diff only removes packages (no unrelated version bumps) — if `npm install` pulls in unrelated updates, investigate before committing rather than accepting a surprise diff.

- [ ] **Step 5: Commit**

```bash
git add -A
git commit -m "chore: remove Electron desktop build tooling, project is web-only

electron/, index.js, scripts/run-desktop.js, and all electron/
electron-builder package.json scripts/deps/config are gone. No
application code depended on Electron -- confirmed via grep before
this task started. engines.node stays >=22.12.0 (Task 2 fixes the
now-inaccurate rationale in README, this task doesn't touch the number)."
```
